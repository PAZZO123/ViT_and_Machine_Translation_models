# Vision Transformer and Machine Translation

Two transformer models from my AI course.

## Notebooks

- `vision_transformer.ipynb`: a Vision Transformer (ViT) for image classification in MindSpore: training, evaluation and inference
- `machine_transformer.ipynb`: a Transformer that translates English to French in PyTorch, with greedy and beam search decoding

## Built with

Python, MindSpore, PyTorch.

## How to run

Open the notebook in Jupyter (or VS Code) and run the cells from top to bottom.
